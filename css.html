CSS - Cascading Style Sheets

CSS ist die Sylesheet-Sprache für Webseiten. Während HTML die Struktur einer Webseite beschreibt, übernimmt CSS die Gestaltung. Mit CSS lassen sich Farben, Schriftarten, Abstände, Animationen und responsive Layouts definieren.

Merke

HTML strukturiert Inhalte - CSS sorgt für deren Aussehen.

Einsatzgebiete

  • Farben und Schriftarten festlegen
  • Responsive Webseiten erstellen
  • Abstände und Größen definieren
  • Animationen und Hover-Effekte erzeugen

Code-Beispiele

body{
            background: #f4f6f9;
            color: #333;
        }

Wichtige Eigenschaften

Eigenschaft Bedeutung
color Textfarbe
background-color Hintergrundfarbe
padding Innenabstand
margin Außenabstand
