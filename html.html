HTML - Hypertext Markup Language

HTML ist die Standard-Auszeichnungssprache zur Strukturierung von Webseiten. Sie definiert den Aufbau einer Seite und bildet die Grundlage für Inhalte wie Überschriften, Texte, Bilder, Tabellen und Formulare. HTML-Dokumente werden von Webbrowsern interpretiert und dargestellt.

Merke

HTML bildet die Grundlage jeder Webseite.

Einsatzgebiete

  • Erstellung von Webseiten
  • Strukturierung von Inhalten
  • Integration von Multimedia-Inhalten
  • Verlinkung weiterer Webseiten

Code-Beispiele

<h1>Willkommen</h1>
            <p>Dies ist eine HTML-Seite.</p>
            <a href="https://www.iu.de">Zur IU</a>

Wichtige HTML-Elemente

Element Beschreibung
<h1> - <h6> Überschriften in verschiedenen Ebenen
<p> Absatztext
<a> Hyperlink zu einer anderen Seite
<img> Einbindung von Bildern

Verwandte Begriffe

HTML arbeitet eng mit CSS und JavaScript zusammen. Daren können außerdem über eine API oder über REST ausgetauscht werden.
