JavaScript

JavaScript erweitert Webseiten um Interaktivität. Formulare können geprüft, Animationen erstellt und Inhalte dynamisch verändert werden. JavaScript ist die Programmiersprache des Webs und wird in allen modernen Browsern unterstützt.

Merke

HTML = Struktur, CSS = Design, JavaScript = Funktionalität

Einsatzgebiete

  • Interaktive Formulare erstellen
  • Animationen und Effekte hinzufügen
  • Dynamische Inhalte laden
  • Spiele und Anwendungen im Browser entwickeln

Code-Beispiele

function hallo(){
            alert("Hallo Welt!");
        }

Wichtige Eigenschaften

Eigenschaft Beschreibung
alert() Zeigt ein Dialogfenster mit einer Nachricht an.
dokument.getElementById() Greift auf ein HTML-Element mit einer bestimmten ID zu.
addEventListener() Reagiert auf Benutzeraktionen wie Klicks oder Tastatureingaben.
fetch() Lädt Daten von einem Server asynchron.
