REST - Representational State Transfer

REST ist ein Architekturstil für Webservices. REST-APIs nutzen in der Regel HTTP und JSON zur Datenkommunikation. Sie ermöglichen eine standardisierte Kommunikation zwischen Client und Server, wobei jede Anfrage unabhängig ist und keine Sitzungsinformationen gespeichert werden.

Merke

Viele moderne Web-Anwendungen nutzen REST-APIs für den Datenaustausch.

Einsatzgebiete

  • Entwicklung von Web-Services
  • Integration von APIs
  • Erstellung von Microservices

Code-Beispiele

GET /api/users
            POST /api/users
            PUT /api/users/1
            DELETE /api/users/1

Wichtige Eigenschaften

Eigenschaft Beschreibung
Stateless Jede Anfrage enthält alle Informationen, die der Server benötigt.
Cacheable Antworten können zwischengespeichert werden, um die Leistung zu verbessern.
Uniform Interface Einheitliche Schnittstelle für die Interaktion mit Ressourcen.
Client-Server Trennung von Client und Server, um die Skalierbarkeit zu erhöhen.
Layered System Die Architektur kann aus mehreren Schichten bestehen, die unabhängig voneinander arbeiten.
